# Lily Garden for Ente Mariamma 🌸

A completely free, responsive animated lily garden in **one HTML file**. Eight colourful SVG lilies grow from their stems, unfurl their leaves and petals, and sway in a dark, glowing landscape.

## Preview on your computer

Double-click `index.html` to open it in Chrome, Safari, Firefox, or Edge. No internet connection, installation, dependencies, or account is needed to preview it.

## Publish free with GitHub Pages

1. The GitHub repository is already created at https://github.com/JithinPatrick05/lily-garden-for-ente-Mariamma.
2. The `index.html` file has already been uploaded to the root of the repository.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**. Set **Branch: main** and **Folder: /(root)**; then click **Save**.
5. Your new site will have an address like `https://YOUR-USERNAME.github.io/lily-garden/` once GitHub completes deployment.

## Edit it

- Change the title or subtitle by editing the `<h1>` and `.subtitle` near the middle of `index.html`.
- Change the lily colours via the `colours` and `presets` arrays near the bottom.
- Change the backgrounds in the `.site` CSS rule.
- Each lily SVG is generated by the `renderGarden` and `bloomMarkup` JavaScript functions.

## Interactions

- **Bloom again:** Replays the grow-and-bloom sequence.
- **New colours:** Randomises the colour assignment and replays.
- **Tap/click a lily:** Change that individual lily to the next colour.
- **Keyboard support:** Focus a lily and press Enter or Space to change its colour.

The site honours `prefers-reduced-motion` accessibility preferences.

Made with no JavaScript frameworks, external fonts, image services or paid hosting requirements.
